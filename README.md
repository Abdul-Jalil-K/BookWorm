BookWorm is an API App that uses Open Library's Free API to generate information about a book based on info sent from the user side. It's a fairly simple, easy project, but considering this is my first time using an API independently, I think it's good to start with something simple so I don't overburden myself with too much, and entirely focus on the API itself.


CONCLUSION

The project is complete.

This one was tough to complete since this was my first time ever working with an API, and my first time using AXIOS independently as well. I was more than a little intimidated at first, as tackling new things often make me, but it was easy enough to do. Open Library's API really made it easy, since it gave me a clean framework for how I wanted to build the form, which would be the main way the user interacted with the API.
