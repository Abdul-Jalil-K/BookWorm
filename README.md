INTRODUCTION

This is the README file for this project: LexiCast.

LexiCast is an API App that uses Merriam-Webster's Free Collegiate Dictionary API to generate a random word, idiom, or phrase based ona  randomly generated number. It's a fairly simple, easy project, but considering this is my first time using an API independently, I think it's good to start with something simple so I don't overburden myself with too much, and entirely focus on the API itself.
